## Objetivo

Que GEASS pueda hacer tres cosas sin navegar ninguna interfaz, por orden expresa de Manuel desde la CLI: abrir una app por un nombre aproximado, abrir el explorador de archivos y pulsar una tecla multimedia. Para lanzar apps se construye un índice con los accesos directos del menú Inicio y las apps que lista `Get-StartApps`, con caché en disco.

Este es el primer paso del crawler que actúa sobre el escritorio. Por eso todo lo que toca el sistema está en un solo módulo pequeño, lo que se puede lanzar o pulsar es una lista cerrada, ante la duda no se hace nada, y cada acción queda en el registro de auditoría.

## Interfaces

### Configuración

Claves nuevas en la sección `launcher` de `crawler.yaml`, todas con comentario "provisional", y sus campos en `Launcher`:

| Clave | Tipo | Valor | Significado |
|---|---|---|---|
| `cache_path` | `str` | `data/crawler/app_index.json` | caché del índice de apps |
| `cache_max_age_s` | `PositiveFloat` | `86400.0` | edad máxima de la caché antes de reconstruirla |
| `start_apps_timeout_s` | `PositiveFloat` | `20.0` | tiempo máximo de `Get-StartApps` |
| `ambiguity_margin` | `FuzzyScore` | `5` | si la segunda mejor coincidencia queda a menos de esto de la primera, hay ambigüedad |
| `max_options` | `PositiveInt` | `5` | opciones que se devuelven cuando hay ambigüedad o no hay coincidencia |

### system.py

Las únicas funciones del paquete que tocan el sistema operativo. Los demás módulos las llaman siempre como atributos del módulo (`system.start_shortcut(...)`), nunca importando la función, para que los tests puedan sustituirlas.

```python
MEDIA_KEYS: dict[str, int] = {
    "play_pause": 0xB3,  # VK_MEDIA_PLAY_PAUSE
    "next": 0xB0,  # VK_MEDIA_NEXT_TRACK
    "previous": 0xB1,  # VK_MEDIA_PREV_TRACK
    "volume_up": 0xAF,  # VK_VOLUME_UP
    "volume_down": 0xAE,  # VK_VOLUME_DOWN
    "mute": 0xAD,  # VK_VOLUME_MUTE
}


def start_shortcut(path: Path) -> None:
    """Abre un acceso directo .lnk, como si se hiciera doble clic sobre él."""


def start_app_id(app_id: str) -> None:
    """Abre una app por su AppID de la carpeta de aplicaciones de Windows."""


def spawn_explorer(path: Path | None) -> None:
    """Abre el explorador de archivos, en una carpeta si se da."""


def send_media_key(action: str) -> None:
    """Pulsa y suelta una tecla multimedia con SendInput."""


def read_start_apps(timeout_s: float) -> str:
    """Salida JSON de Get-StartApps en PowerShell."""
```

- `start_shortcut`: `os.startfile(path)`. Antes comprueba que la extensión es `.lnk` (sin distinguir mayúsculas) y que el archivo existe; si no, `ActionError`. Un `OSError` de Windows se convierte en `ActionError`.
- `start_app_id`: `subprocess.Popen(["explorer.exe", f"shell:AppsFolder\\{app_id}"])`, sin `shell=True`. `app_id` vacío, o con comillas, saltos de línea o espacios al principio o al final: `ActionError`.
- `spawn_explorer`: `subprocess.Popen(["explorer.exe"])` o `["explorer.exe", str(path)]`, sin `shell=True`.
- `send_media_key`: `action` debe ser una clave de `MEDIA_KEYS`; si no, `ActionError` sin llamar a nada. Envía con `SendInput` (ctypes) dos eventos de teclado: tecla presionada y tecla soltada (`KEYEVENTF_KEYUP` 0x0002), con el código virtual de `MEDIA_KEYS`. Si `SendInput` devuelve menos de 2, `ActionError`. Esta función no acepta códigos de tecla: solo los nombres de esa lista cerrada. Es el único uso de `SendInput` en todo el proyecto.
- `read_start_apps`: ejecuta `powershell.exe -NoProfile -NonInteractive -Command "[Console]::OutputEncoding=[Text.Encoding]::UTF8; Get-StartApps | ConvertTo-Json -Compress"` con `subprocess.run`, captura stdout como UTF-8 y aplica `timeout_s`. Si falla, tarda de más o sale con código distinto de 0, lanza `ActionError`.

### audit.py

```python
class AuditLog:
    """Registro de auditoría en JSON Lines. Cada acción hecha o rechazada es una línea."""

    def __init__(self, path: Path, *, clock: Callable[[], datetime] = ...) -> None: ...  # UTC

    @classmethod
    def from_config(cls, safety: SafetyConfig | None = None) -> "AuditLog": ...

    def record(
        self, *, action: str, target: str, app: str, result: str, authorized_by: str
    ) -> None: ...
```

- `from_config` usa `safety.crawler.audit_log.path` (resuelta con `resolve_project_path`); sin argumento carga `load_safety_config()`.
- `record` añade una línea JSON con las claves `at` (ISO 8601 en UTC), `action`, `target`, `app`, `result` y `authorized_by`, con `ensure_ascii=False`. Crea la carpeta si falta. `authorized_by` vacío: `ValueError`.
- Es la regla de `CLAUDE.md`: "qué acción, sobre qué elemento, en qué app, resultado y quién la autorizó".

### index.py

```python
AppSource = Literal["shortcut", "start_apps"]


class AppEntry(BaseModel):  # frozen
    name: str  # nombre visible
    source: AppSource
    shortcut_path: str | None  # ruta del .lnk, si source es "shortcut"
    app_id: str | None  # AppID, si source es "start_apps"
    blocked: bool  # el nombre coincide con la lista de bloqueo de safety.yaml


class AppIndex:
    def __init__(self, entries: Sequence[AppEntry], *, built_at: datetime) -> None: ...

    @property
    def entries(self) -> list[AppEntry]: ...  # ordenadas por nombre normalizado

    @property
    def built_at(self) -> datetime: ...

    @classmethod
    def build(
        cls, config: CrawlerConfig, safety: SafetyConfig, *, clock: Callable[[], datetime] = ...
    ) -> "AppIndex": ...

    @classmethod
    def load(
        cls,
        config: CrawlerConfig,
        safety: SafetyConfig,
        *,
        refresh: bool = False,
        cache_path: Path | None = None,
        clock: Callable[[], datetime] = ...,
    ) -> "AppIndex": ...

    def save(self, path: Path) -> None: ...
```

- `build`:
  1. Recorre cada carpeta de `launcher.start_menu_dirs`, en el orden de la lista, con las variables de entorno expandidas (`os.path.expandvars`) y de forma recursiva. Toma solo los archivos con extensión `.lnk`. El nombre es el nombre del archivo sin la extensión. Una carpeta que no existe se salta.
  2. Si `launcher.include_store_apps` es verdadero, llama a `system.read_start_apps(launcher.start_apps_timeout_s)` y lee el JSON: una lista de objetos con `Name` y `AppID`, o un solo objeto si hay una sola app. Si la llamada lanza `ActionError` o el JSON no es válido, se registra un aviso en el log y el índice sigue solo con los accesos directos.
  3. Los nombres se limpian con `strip()`; una entrada con nombre vacío se descarta.
  4. Duplicados: dos entradas con el mismo `normalize_text(name)` son la misma app. Gana la primera en este orden: accesos directos en el orden de las carpetas y, dentro de cada carpeta, por ruta; después las de `Get-StartApps` en su orden.
  5. `blocked` es verdadero si `normalize_text(name)` contiene alguno de los `safety.crawler.blocklist_patterns` (pasados también por `normalize_text`).
- `load`: `cache_path` por defecto es `resolve_project_path(launcher.cache_path)`. Si `refresh` es falso, el archivo existe, se puede leer y su `built_at` tiene menos de `cache_max_age_s`, se usa la caché. En cualquier otro caso (no existe, es antigua, está corrupta o `refresh` es verdadero) se llama a `build` y se guarda. Una caché corrupta nunca es un error: se reconstruye.
- `save`: JSON con `built_at` (ISO 8601 en UTC) y `entries`, escritura atómica (temporal en la misma carpeta y `os.replace`), creando la carpeta si falta. `blocked` se guarda, pero al leer la caché se recalcula con la lista de bloqueo actual.
- El índice no resuelve a qué apunta cada `.lnk` ni ejecuta nada.

### launcher.py

```python
LaunchStatus = Literal["launched", "would_launch", "ambiguous", "not_found", "blocked"]


class AppMatch(BaseModel):  # frozen
    entry: AppEntry
    score: float  # 0 a 100


class LaunchResult(BaseModel):  # frozen
    query: str
    status: LaunchStatus
    entry: AppEntry | None  # la app elegida; None si es ambiguo o no hay coincidencia
    options: list[AppMatch]  # opciones a mostrar; vacía si se eligió una


def match_app(index: AppIndex, name: str, config: CrawlerConfig) -> LaunchResult: ...


def launch(
    name: str,
    *,
    authorized_by: str,
    index: AppIndex | None = None,
    config: CrawlerConfig | None = None,
    safety: SafetyConfig | None = None,
    audit: AuditLog | None = None,
    dry_run: bool = False,
) -> LaunchResult: ...
```

`match_app` no lanza nada; solo decide. Con `q = normalize_text(name)`:

1. `q` vacío: `ValueError`.
2. Puntuación de cada entrada: `100.0` si `normalize_text(entry.name) == q`; si no, `rapidfuzz.fuzz.WRatio(q, normalize_text(entry.name))`.
3. Candidatas: las de puntuación mayor o igual que `launcher.fuzzy_match_threshold`, ordenadas por puntuación descendente y luego por nombre normalizado.
4. Sin candidatas: `not_found`, con `options` igual a las `max_options` entradas de mayor puntuación (aunque no lleguen al umbral), para sugerirlas.
5. Si hay exactamente una entrada con coincidencia exacta, es la elegida, aunque otras tengan puntuación alta.
6. Si no hay coincidencia exacta y hay dos o más candidatas, y la segunda está a menos de `ambiguity_margin` puntos de la primera: `ambiguous`, con `options` igual a las primeras `max_options` candidatas y `entry=None`. No se adivina.
7. En otro caso, la elegida es la primera candidata.
8. Con una elegida: si `entry.blocked`, estado `blocked`; si no, `would_launch`. En ambos, `entry` es la elegida y `options` está vacía.

`launch`:

- `authorized_by` vacío: `ValueError`. Los valores por defecto: `config` y `safety` se cargan; `index` es `AppIndex.load(config, safety)`; `audit` es `AuditLog.from_config(safety)`.
- Llama a `match_app`. Solo si el estado es `would_launch` y `dry_run` es falso, lanza: `system.start_shortcut(Path(entry.shortcut_path))` si la fuente es `shortcut`, o `system.start_app_id(entry.app_id)` si es `start_apps`, y devuelve el resultado con estado `launched`.
- Con `dry_run` devuelve `would_launch` sin lanzar y sin escribir en la auditoría.
- Auditoría, sin `dry_run`: una línea por llamada, con `action="launch"`, `target` igual al texto pedido, `app` igual al nombre de la app elegida (o cadena vacía) y `result` igual al estado final (`launched`, `ambiguous`, `not_found`, `blocked`), o `error: <mensaje>` si el lanzamiento lanzó `ActionError`. En ese último caso el error se vuelve a lanzar después de registrarlo.
- Nunca se lanza una ruta ni un comando que dé el usuario: solo entradas del índice.

### direct.py

```python
MediaAction = Literal["play_pause", "next", "previous", "volume_up", "volume_down", "mute"]

DIRECT_ACTION_KEYS: dict[str, str] = {
    "explorer": "open_explorer",
    "play_pause": "media_play_pause",
    "next": "media_next",
    "previous": "media_previous",
    "volume_up": "volume_up",
    "volume_down": "volume_down",
    "mute": "volume_mute",
}


def open_explorer(
    path: str | Path | None = None,
    *,
    authorized_by: str,
    config: CrawlerConfig | None = None,
    audit: AuditLog | None = None,
) -> Path | None: ...


def media(
    action: MediaAction,
    *,
    authorized_by: str,
    config: CrawlerConfig | None = None,
    audit: AuditLog | None = None,
) -> None: ...
```

- Las dos comprueban primero que su clave de `DIRECT_ACTION_KEYS` está en `launcher.direct_actions`; si no, `ActionDisabledError`, que nombra la clave.
- `open_explorer`: sin ruta abre el explorador sin más y devuelve `None`. Con ruta: expande `~` y variables de entorno, la resuelve a absoluta, y debe ser una carpeta que existe; si no, `ActionError` sin abrir nada. Llama a `system.spawn_explorer` y devuelve la ruta resuelta.
- `media`: `action` fuera de `MediaAction`: `ActionError`. Llama a `system.send_media_key(action)`.
- Las dos registran en la auditoría: `action` igual a `open_explorer` o `media`, `target` igual a la ruta resuelta (o cadena vacía) o a la acción multimedia, `app="explorer.exe"` o `app=""`, y `result` igual a `done`, `disabled`, o `error: <mensaje>`. `authorized_by` vacío: `ValueError`.

### CLI (`__main__.py`)

Grupo de typer `do`, registrado con `app.add_typer(..., name="do")`, con esta ayuda: "Acciones directas por orden tuya: abrir apps, el explorador y teclas multimedia." Las importaciones de `geass.crawler.actions` van dentro de cada comando. Todas las llamadas pasan `authorized_by="cli:manuel"`.

```
python -m geass.crawler do launch NOMBRE [--refresh] [--dry-run]
python -m geass.crawler do media ACCION
python -m geass.crawler do explorer [RUTA]
python -m geass.crawler do apps [--refresh]
```

- `do launch`:
  - `launched`: imprime `Abriendo {nombre}.` y sale con 0.
  - `would_launch` (con `--dry-run`): imprime `Se abriría {nombre}.` y sale con 0.
  - `ambiguous`: imprime `'{texto}' es ambiguo. Opciones:` y una línea por opción, `  {n}. {nombre} ({puntuación con un decimal})`; sale con 2 sin abrir nada.
  - `not_found`: imprime `No hay ninguna app que coincida con '{texto}'.` y, si hay sugerencias, `Parecidas:` con el mismo formato; sale con 1.
  - `blocked`: imprime `{nombre} coincide con la lista de bloqueo de safety.yaml y no se abre.`; sale con 1.
  - `--refresh` reconstruye el índice antes de buscar.
- `do media ACCION`: `ACCION` es uno de `play_pause`, `next`, `previous`, `volume_up`, `volume_down`, `mute`; otro valor sale con código 2 (validación de typer). Imprime `Hecho: {acción}.`.
- `do explorer [RUTA]`: imprime `Explorador abierto.` o `Explorador abierto en {ruta}.`.
- `do apps`: imprime `{n} apps en el índice (construido el {fecha UTC}).` y después una línea por app con su nombre; las bloqueadas llevan ` [bloqueada]` al final.
- Cualquier `GeassError` o `ValueError` se imprime en rojo con `_error` y sale con 1.
