- `allows_window` devuelve `False` si `window.identified` es falso, o si `window.process_name.strip().lower()` está en la lista de excluidas (comparada sin mayúsculas ni espacios sobrantes). En otro caso, `True`.

- No hay campo ni método para valores de texto: `NodeProps` no los tiene y no se añade ninguna lectura nueva.

```python
MODIFIER_NAMES: tuple[str, ...] = ("ctrl", "alt", "shift", "win")
ALT_GR = "alt_gr"


class ShortcutTracker:
    """Decide qué pulsaciones son un atajo. Sin hilos ni pynput."""

    def press(self, name: str, at: float) -> ShortcutPressed | None: ...
    def release(self, name: str) -> None: ...
    def reset(self) -> None: ...
```

Reglas de `ShortcutTracker` (son la regla "nunca teclas sueltas"):

- `name` es `"ctrl"`, `"alt"`, `"shift"`, `"win"`, `"alt_gr"` o el nombre de una tecla normal (`"s"`, `"5"`, `"f5"`, `"enter"`, `"vk191"`).
- Al presionar un modificador o `alt_gr` solo se anota que está presionado. Devuelve `None`.
- Al presionar una tecla normal se emite un atajo solo si está presionado al menos uno de `ctrl`, `alt` o `win`, y `alt_gr` no está presionado. `shift` solo no cuenta: mayúscula más letra es escritura. Con `alt_gr` presionado nunca se emite: en teclado español AltGr escribe caracteres como `@`.
- El `combo` es canónico: modificadores presionados en el orden `ctrl`, `alt`, `shift`, `win`, y luego la tecla, unidos con `+`. Ejemplo: `"ctrl+shift+s"`.
- Si la tecla normal se mantiene presionada (autorrepetición), el atajo se emite una sola vez, hasta que se suelte esa tecla.
- Una tecla normal sin modificador válido devuelve `None` y no se guarda en ningún sitio: ni en el objeto, ni en el log.
- El objeto solo puede guardar: el conjunto de modificadores presionados y el nombre de la tecla del último atajo emitido (para la autorrepetición). `reset()` lo borra todo.

```python
def key_name(key: Any) -> str | None:
    """Nombre canónico de una tecla de pynput, o None si no se reconoce."""


class ShortcutListener:
    """Escucha del teclado con pynput. Solo existe si capture_shortcuts es verdadero."""

    def __init__(
        self,
        sink: Callable[[ShortcutPressed], None],
        *,
        pause: PauseState,
        clock: Callable[[], float] = time.perf_counter,
    ) -> None: ...
    def start(self) -> None: ...
    def stop(self) -> None: ...
```

- `key_name`: `Key.ctrl`, `ctrl_l`, `ctrl_r` -> `"ctrl"`; `Key.alt`, `alt_l` -> `"alt"`; `Key.alt_gr`, `alt_r` -> `"alt_gr"`; `Key.shift*` -> `"shift"`; `Key.cmd*` -> `"win"`; otras `Key` -> su `name`. Para `KeyCode` se usa siempre `vk`, nunca `char` (con Ctrl presionado `char` es un carácter de control): `vk` de `0x30` a `0x39` y de `0x41` a `0x5A` -> el carácter en minúscula; otro `vk` -> `f"vk{vk}"`; sin `vk` -> `None`.
- `ShortcutListener` importa pynput dentro de `start` (como `MouseListener`), usa `pynput.keyboard.Listener` con `on_press` y `on_release`, pasa cada tecla por `key_name` y `ShortcutTracker`, y entrega los atajos a `sink`. Si `pause.is_paused()` no entrega nada y hace `reset()` del tracker. El callback no deja escapar excepciones. No usa `pynput.keyboard.Controller`.

### hotkey.py

```python
class HotkeyError(GeassError):
    """El atajo global no es válido o no se pudo registrar."""


def parse_hotkey(text: str) -> tuple[int, int]:
    """Convierte "ctrl+alt+p" en (modificadores MOD_*, código de tecla virtual)."""


class PauseHotkey:
    """Atajo global mediante RegisterHotKey de Win32, en un hilo propio."""

    def __init__(self, hotkey: str, on_trigger: Callable[[], None]) -> None: ...
    def start(self) -> None: ...
    def stop(self) -> None: ...
```

- Decisión de diseño: el atajo de pausa usa `RegisterHotKey` y no un gancho de teclado. Así, con `capture_shortcuts: false`, el proceso no observa ninguna tecla: Windows solo le avisa de esa combinación.
- `parse_hotkey`: partes separadas por `+`, sin distinguir mayúsculas, con espacios tolerados. Modificadores: `ctrl` (`MOD_CONTROL` 0x0002), `alt` (`MOD_ALT` 0x0001), `shift` (`MOD_SHIFT` 0x0004), `win` (`MOD_WIN` 0x0008). Exactamente una tecla: letra `a` a `z`, dígito `0` a `9` (su código ASCII en mayúscula) o `f1` a `f24` (`0x70` + n - 1). Debe haber al menos uno de `ctrl`, `alt` o `win`. Cualquier otra cosa lanza `HotkeyError` con un mensaje que cite el texto recibido. Ejemplo: `parse_hotkey("ctrl+alt+p") == (0x0003, 0x50)`.
- `start` crea un hilo `daemon` que llama a `RegisterHotKey(None, id, mods | MOD_NOREPEAT (0x4000), vk)` y luego bombea mensajes con `GetMessageW`; con cada `WM_HOTKEY` (0x0312) llama a `on_trigger()` (protegido: una excepción se registra en el log y no mata el hilo). `start` espera a saber si el registro funcionó y, si no, lanza `HotkeyError` ("el atajo ya está en uso por otra aplicación o no se pudo registrar").
- `stop` envía `WM_QUIT` al hilo con `PostThreadMessageW`, espera a que termine y el hilo llama a `UnregisterHotKey` antes de salir. Llamar a `stop` sin `start` no hace nada.
- Usa `ctypes` o `pywin32`, que ya están instalados.

### cpu.py

```python
@dataclass(frozen=True)
class CpuUsage:
    wall_s: float
    cpu_s: float
    logical_cpus: int

    @property
    def process_fraction(self) -> float: ...  # cpu_s / wall_s; 0.0 si wall_s <= 0
    @property
    def machine_fraction(self) -> float: ...  # process_fraction / logical_cpus


class CpuMeter:
    def __init__(
        self,
        *,
        wall_clock: Callable[[], float] = time.perf_counter,
        cpu_clock: Callable[[], float] = time.process_time,
        logical_cpus: int | None = None,  # por defecto os.cpu_count() o 1
    ) -> None: ...
    def start(self) -> None: ...
    def read(self) -> CpuUsage: ...  # desde start(); RuntimeError si no se llamó a start
```

- `time.process_time` suma el tiempo de CPU de todos los hilos del proceso. No se añade psutil.
- `process_fraction` es la fracción de un núcleo; `machine_fraction`, la de toda la máquina (lo que muestra el Administrador de tareas). El presupuesto `passive.cpu_budget_fraction` se compara con `process_fraction`, la más estricta.

`PassiveRunner.run`, en este orden:

1. Valores por defecto: `stop_signal` -> `NamedStopEvent()` (si ya existe, `AlreadyRunningError` antes de abrir nada); `store` -> `CrawlerStore.from_config(config)`; `sensor` -> `WinSensor.from_config(config)` (importado dentro de `run`, para que el módulo se pueda importar sin Windows); `status_path` -> `resolve_project_path(config.passive.status_path)`; `cpu_meter` -> `CpuMeter()`.
2. `session_id = store.start_session("passive")`.
3. Crea un único `PauseState`, un único `PassiveStats` y un único reloj (`time.perf_counter`) y los comparte entre `PassiveObserver`, `PressCapturer`, `MouseListener` y `ShortcutListener`. `ConfigPrivacyPolicy.from_config(config)`, `SignatureRules.from_config(config.signature)`, `ObserverSettings.from_config(config.passive)`, `excluded_apps=config.apps.excluded`, `max_delay_s=config.passive.max_capture_delay_s`. Si el sensor tiene `thread_setup` y `thread_teardown` (`getattr`), se pasan al observador y al capturador.
4. Arranca: observador, capturador y, si `listeners` es verdadero: `PauseHotkey(config.passive.pause_hotkey, pause.toggle)` siempre; `MouseListener(capturer.submit, clock=...)` si `config.passive.listen_mouse`; `ShortcutListener(observer.post, pause=..., clock=...)` solo si `config.passive.capture_shortcuts`. El atajo de pausa se arranca primero: si falla con `HotkeyError`, no se arranca nada más, se cierra la sesión con una nota que lo diga y el error sale hacia fuera. No se corre sin atajo de pausa cuando `listeners` es verdadero.
5. Si `config.passive.use_uia_events` es verdadero, escribe una línea de log de nivel info: los eventos de UI Automation todavía no están implementados y se usa solo el sondeo. No falla.
6. `cpu_meter.start()` y bucle principal: `stop_signal.wait(timeout)` en tramos de como mucho 0.5 s (para que Ctrl+C responda); cada `config.passive.status_interval_s` escribe el estado. Sale cuando la señal se activa, cuando pasan `duration_s` segundos (si no es `None`) o con `KeyboardInterrupt` (se captura y se trata como parada normal).
7. Parada, siempre (bloque `finally`), en este orden: escucha del mouse, escucha de atajos, atajo de pausa, capturador, observador. Después `store.end_session(session_id, notes=...)` con un JSON de `{"cpu_fraction": ..., "wall_s": ..., "counters": {...}}`, estado final con `running=False`, cierre del `NamedStopEvent` si lo creó el runner y cierre de la base si la abrió el runner.
8. Devuelve el `PassiveStatus` final.

Estado en disco: `PassiveStatus.model_dump_json(indent=2)` en `status_path`, escrito de forma atómica (archivo temporal en la misma carpeta y `os.replace`), creando la carpeta si falta. Solo contiene números, fechas y el pid: ningún nombre de app, ventana ni elemento.

- `request_stop`: abre el evento con nombre y lo activa. Devuelve `False` si no existe (no hay proceso en marcha), sin crearlo.
- `read_status`: devuelve el `PassiveStatus` leído de `status_path`, o `None` si el archivo no existe. Si el archivo existe pero no se puede validar, lanza `PassiveError`.

### CLI (`__main__.py`)

Grupo de typer `passive`, registrado con `app.add_typer(..., name="passive")`, con ayuda en español. Las importaciones de `geass.crawler.passive.runner` van dentro de cada comando, como hacen `dump` y `compare`.

- `python -m geass.crawler passive start [--duration SEGUNDOS]`: antes de arrancar imprime (en `console`, stderr) el atajo de pausa, la ruta de la base y cómo parar (`Ctrl+C` o `passive stop` desde otra terminal). Llama a `PassiveRunner(load_crawler_config()).run(duration_s=duration)`. Al terminar imprime el resumen: duración, estados registrados, estados nuevos, transiciones, clics vistos, uso de CPU como porcentaje de un núcleo y de la máquina, y si quedó dentro del presupuesto. `--duration` debe ser mayor que 0. Un `GeassError` se imprime en rojo y sale con código 1.
- `python -m geass.crawler passive stop`: llama a `request_stop()`. Si devuelve `False`, imprime "No hay ningún crawler pasivo en marcha." y sale con código 1. Si devuelve `True`, imprime que se pidió la parada y sale con 0.
- `python -m geass.crawler passive stats`: imprime por stdout el último `PassiveStatus` (en marcha o detenido, desde cuándo, CPU y contadores distintos de cero) y, si el archivo de la base existe, los `counts()` de la base. Si no hay archivo de estado, lo dice. No crea la base si no existe.
