# O00: función geass.core.version()

- **Paso de PROMPT_CHAIN.md:** ninguno. Es la prueba de humo del protocolo de orquestación.
- **Fecha:** 2026-11-11
- **Lecturas obligatorias:** `CLAUDE.md`; `pyproject.toml`; `src/geass/__init__.py`; `src/geass/core/__init__.py`.

## Objetivo

Que cualquier módulo pueda preguntar la versión instalada de GEASS con `geass.core.version()`. La versión tiene una sola fuente de verdad: el campo `version` de `pyproject.toml`.

## Archivos

| Archivo | Acción | Contenido |
|---|---|---|
| `src/geass/core/package_info.py` | crear | la función `version` |
| `src/geass/core/__init__.py` | modificar | importar `version` desde `geass.core.package_info` y añadir `"version"` a `__all__`, en orden alfabético |
| `tests/core/test_package_info.py` | crear | los tests de abajo |

Solo se tocan esos tres archivos. El módulo no se llama `version.py` a propósito: así `geass.core.version` es solo la función y no hay un submódulo con el mismo nombre.

## Interfaces

```python
# src/geass/core/package_info.py
PACKAGE_NAME = "geass"


def version() -> str:
    """Devuelve la versión instalada del paquete geass, por ejemplo "0.1.0"."""
```

- Lee la versión con `importlib.metadata.version(PACKAGE_NAME)`.
- No lee `pyproject.toml` en tiempo de ejecución ni devuelve una cadena escrita a mano.
- Si el paquete no está instalado, deja pasar `importlib.metadata.PackageNotFoundError` sin capturarla.
- Sin dependencias nuevas: `importlib.metadata` es de la biblioteca estándar.

## Casos de prueba

En `tests/core/test_package_info.py`, todos rápidos y sin marker:

1. `version()` devuelve un `str` no vacío.
2. `version()` es igual al campo `project.version` de `pyproject.toml`, leído con `tomllib` desde `geass.core.paths.project_root() / "pyproject.toml"`.
3. `version()` es igual a `geass.__version__`.
4. `from geass.core import version` funciona, es la misma función que `geass.core.package_info.version`, y `"version"` está en `geass.core.__all__`.
