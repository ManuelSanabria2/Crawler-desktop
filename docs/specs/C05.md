### model.py

```python
class GraphError(GeassError):
    """Problema al consultar el grafo del crawler."""


class AppNotFoundError(GraphError): ...  # ninguna app coincide con el texto


class AmbiguousAppError(GraphError): ...  # dos o más apps empatan como mejor coincidencia


class StateNotFoundError(GraphError): ...  # el estado no existe o no es de esa app


class TargetNotFoundError(GraphError): ...  # ningún elemento coincide con el objetivo


class NoRouteError(GraphError): ...  # hay objetivo, pero no ruta ejecutable hasta él


class ElementMatch(BaseModel):  # frozen
    element: ElementRecord
    state_id: int
    state_title: str  # StateRecord.title_pattern
    score: float  # 0 a 100


class RouteStep(BaseModel):  # frozen
    state_id: int  # estado en el que se hace la acción
    element: ElementRecord
    action_type: ActionType
    expected_state_id: int | None  # estado al que lleva; None en el paso final
    transition_id: int | None  # None en el paso final
    description: str  # texto legible en español


class Route(BaseModel):  # frozen
    app: AppRecord
    start_state_id: int
    target: ElementMatch
    steps: list[RouteStep]
    cost: float  # suma de los costes de las transiciones; el paso final no suma

    def describe(self) -> list[str]: ...  # ["1. ...", "2. ..."] con la description de cada paso


class AppCoverage(BaseModel):  # frozen
    app: AppRecord
    states: int
    visits: int
    elements: int
    actionable_elements: int
    exercised_elements: int
    element_coverage: float
    transitions: int
    observations: int
    passive_transitions: int
    active_transitions: int
    executable_transitions: int
    transitions_without_element: int
    isolated_states: int
    dead_end_states: int
```

### build.py

```python
ACTION_PATTERNS: tuple[str, ...] = ("Invoke", "Toggle", "ExpandCollapse", "SelectionItem")
EXECUTABLE_ACTIONS: frozenset[str] = frozenset(
    {"invoke", "toggle", "expand_collapse", "select", "coordinate_click"}
)


def is_executable(transition: TransitionRecord) -> bool:
    """Verdadero si la transición se puede repetir: tiene elemento y una acción conocida."""


class CrawlerGraph:
    """Grafo dirigido de estados y transiciones, con las consultas del crawler."""

    def __init__(
        self,
        apps: Sequence[AppRecord],
        states: Sequence[StateRecord],
        elements: Sequence[ElementRecord],
        transitions: Sequence[TransitionRecord],
        *,
        fuzzy_match_threshold: int,
        coordinate_click_cost: float,
    ) -> None: ...

    @classmethod
    def from_store(
        cls, store: CrawlerStore, config: CrawlerConfig | None = None
    ) -> "CrawlerGraph": ...

    @property
    def graph(self) -> nx.MultiDiGraph: ...

    def resolve_app(self, app: str) -> AppRecord: ...

    def find_element(
        self, app: str, text: str, *, limit: int = 10, min_score: float | None = None
    ) -> list[ElementMatch]: ...

    def path_to(self, app: str, current_state: int, target: str | int) -> Route: ...

    def coverage(self, app: str | None = None) -> list[AppCoverage]: ...
```

**Construcción**

- `from_store` lee con la interfaz pública de `CrawlerStore`: `list_apps()`, `list_states()`, `list_elements(state_id)` por cada estado y `list_transitions()`. Si `config` es `None`, carga `load_crawler_config()`. Usa `config.graph.fuzzy_match_threshold` y `config.graph.coordinate_click_cost`. No escribe en la base.
- `graph` es un `networkx.MultiDiGraph`:
  - un nodo por estado, con clave el id del estado (entero) y atributos `app_id`, `executable` (el de la app), `title` (`title_pattern`) y `visits`;
  - una arista por transición, de `source_state_id` a `target_state_id`, con `key` igual al id de la transición y atributos `transition_id`, `element_id`, `action_type`, `source`, `count`, `mean_latency_s`, `executable` (resultado de `is_executable`) y `cost`.
  - Los nodos se añaden en orden de id de estado y las aristas en orden de id de transición.
- `is_executable`: `element_id is not None` y `action_type in EXECUTABLE_ACTIONS`. Quedan fuera `unknown` (no se sabe qué se hizo) y `set_value` (haría falta un valor que la base no guarda).
- `cost` de una arista: `coordinate_click_cost` si `action_type == "coordinate_click"`; `1.0` en otro caso.
- Una transición cuyo elemento ya no está entre los elementos leídos se trata como sin elemento (no ejecutable).

**`resolve_app(app)`**

1. Se compara `normalize_text(app)` con, para cada app: su `executable`, su `executable` sin la extensión `.exe`, y su `display_name`, todos pasados por `normalize_text`. Si exactamente una app coincide de forma exacta, se devuelve.
2. Si no hay coincidencia exacta, se puntúa cada app con el máximo de `rapidfuzz.fuzz.WRatio` entre el texto normalizado y esos mismos tres nombres. Se queda con las de puntuación mayor o igual que `fuzzy_match_threshold`.
3. Sin candidatas: `AppNotFoundError`, con un mensaje que cite el texto y liste los ejecutables conocidos. Si las dos mejores empatan en puntuación (o hay dos coincidencias exactas): `AmbiguousAppError`, citando ambas. En otro caso, la mejor.

**`find_element(app, text, limit, min_score)`**

- Resuelve la app con `resolve_app`. Candidatos: los elementos de los estados de esa app cuyo nombre normalizado no está vacío. Los elementos de otras apps nunca aparecen.
- Puntuación: `rapidfuzz.fuzz.WRatio(normalize_text(text), normalize_text(element.name))`.
- Se devuelven los que tienen puntuación mayor o igual que `min_score` (por defecto, `fuzzy_match_threshold`).
- Orden: puntuación descendente; a igual puntuación, más visitas del estado primero; después, id de elemento ascendente. Se cortan a `limit`.
- El mismo nombre en dos estados da dos resultados, uno por estado.
- `text` vacío tras normalizar, o `limit < 1`: `ValueError`.

**`path_to(app, current_state, target)`**

- `current_state` es un id de estado. Si no existe o no pertenece a la app resuelta: `StateNotFoundError`.
- Objetivos candidatos:
  - `target` entero: el elemento con ese id. Si no existe o no es de esa app: `TargetNotFoundError`. Su `ElementMatch` lleva `score=100.0`.
  - `target` texto: todos los resultados de `find_element(app, target, limit=<sin corte>)` que empatan en la puntuación más alta. Si no hay ninguno: `TargetNotFoundError`.
- Para la búsqueda solo cuentan las aristas con `executable=True`. Entre dos estados con varias aristas ejecutables se usa una sola: la de menor `cost`; a igual coste, la de mayor `count`; después, la de menor id.
- Para cada candidato se calcula la ruta de coste mínimo (algoritmo de Dijkstra de networkx con `cost`) desde `current_state` hasta el estado que contiene el elemento. Si el elemento está en el estado actual, la ruta tiene coste 0 y ninguna transición.
- Se elige el candidato alcanzable de menor coste; a igual coste, el de más visitas de su estado; después, el de menor id de elemento. Si ninguno es alcanzable: `NoRouteError`, con un mensaje que diga cuántos candidatos había.
- `steps`: un paso por cada transición de la ruta, con el elemento de la transición, su `action_type`, `expected_state_id` igual al destino y su `transition_id`. Después, siempre, un paso final sobre el elemento objetivo, en su estado, con `expected_state_id=None`, `transition_id=None` y `action_type = infer_action("left", tuple(element.patterns))` (función de `geass.crawler.passive.pointer`).
- `description` de cada paso: `{verbo} "{nombre}" ({tipo de control})`. Verbos: `invoke` -> `Pulsar`; `toggle` -> `Alternar`; `expand_collapse` -> `Desplegar`; `select` -> `Seleccionar`; `coordinate_click` -> `Hacer clic en`. Si el nombre del elemento está vacío se usa su AutomationId entre corchetes en lugar del nombre entre comillas (`Pulsar [btnSave] (Button)`); si también está vacío, `[sin nombre]`. Ejemplo: `Desplegar "Archivo" (MenuItem)`.
- `Route.describe()` devuelve las descripciones numeradas desde 1: `"1. Desplegar \"Archivo\" (MenuItem)"`.

**`coverage(app)`**

- Con `app=None`, una entrada por cada app, ordenadas por `executable`. Con `app`, solo la app resuelta (lista de un elemento).
- Las transiciones se cuentan en la app del estado de origen.
- Campos:
  - `states`: estados de la app. `visits`: suma de sus `visits`.
  - `elements`: elementos guardados de esos estados.
  - `actionable_elements`: los que tienen `enabled=True` y al menos un patrón de `ACTION_PATTERNS`.
  - `exercised_elements`: elementos accionables distintos que aparecen como `element_id` en alguna transición de la app.
  - `element_coverage`: `exercised_elements / actionable_elements`, o `0.0` si no hay accionables.
  - `transitions`: filas de transición. `observations`: suma de sus `count`.
  - `passive_transitions` y `active_transitions`: filas según `source`.
  - `executable_transitions`: filas con `is_executable`.
  - `transitions_without_element`: filas con `element_id is None`.
  - `isolated_states`: estados sin ninguna transición de entrada ni de salida (de cualquier tipo).
  - `dead_end_states`: estados sin ninguna transición ejecutable de salida.

### CLI (`__main__.py`)

Las importaciones de `geass.crawler.graph` van dentro de cada comando. Los resultados van por stdout con `typer.echo`; los errores, en rojo por `console` (stderr).

```
python -m geass.crawler query TEXTO --app NOMBRE [--from ID_ESTADO] [--limit N] [--db RUTA]
python -m geass.crawler coverage [--app NOMBRE] [--db RUTA]
```

- `--db`: ruta de la base. Por defecto, `resolve_project_path(config.store.db_path)`. Si el archivo no existe, se imprime "La base todavía no existe: <ruta>" y se sale con código 1, sin crearlo.
- `query`: `--app` es obligatorio; `--limit` por defecto 10. Imprime una línea por coincidencia con este formato: `{puntuación con un decimal}  "{nombre}" ({tipo de control})  estado {id}: {título del estado}`. Sin coincidencias: imprime "Sin coincidencias para '<texto>' en <ejecutable>." y sale con código 1.
- `query --from ID`: después de las coincidencias imprime una línea en blanco, la línea `Ruta desde el estado {id}:` y las líneas de `Route.describe()`. La ruta se calcula con `path_to(app, ID, TEXTO)`.
- `coverage`: por cada app, un bloque que empieza con `{display_name} ({executable})` y sigue con una línea por campo, con sangría de dos espacios y etiquetas en español; `element_coverage` como porcentaje sin decimales. Con la base vacía de apps imprime "La base no tiene ninguna app registrada." y sale con 0.
- Cualquier `GeassError` (incluidos los `GraphError`) se imprime en rojo y sale con código 1.
