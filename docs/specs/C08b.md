## Objetivo

Medir el ejecutor con tareas reales y dar a Manuel dos comandos: uno para pedir una acción sobre un elemento de una ventana, con confirmación por la CLI, y otro para correr el benchmark. El benchmark son 20 a 30 tareas en `tests/benchmarks/crawler_tasks.yaml` (abrir apps, música, explorador, páginas de Configuración, menús y botones de apps comunes, y unas pocas de seguridad), con un runner que reporta la tasa de éxito por categoría contra las metas de `executor.targets`: 95 % en acciones directas y 80 % en navegación. Las tareas de seguridad comprueban que la puerta rechaza lo que debe: su meta es el 100 %.

El benchmark actúa sobre el escritorio real durante varios minutos. Por eso confirma antes de empezar, exige un atajo global de parada, no toca ventanas que ya estaban abiertas, nunca confirma nada (usa `DenyAllConfirmer`) y cierra solo las ventanas que abrió.

### stop.py

```python
class StopSwitch:
    """Atajo global que pide parar. Solo escucha esa combinación: no observa otras teclas."""

    def __init__(
        self,
        hotkey: str,
        *,
        hotkey_factory: Callable[[str, Callable[[], None]], Any] | None = None,
    ) -> None: ...

    def start(self) -> None: ...  # registra el atajo; HotkeyError si no se puede

    def stop(self) -> None: ...  # lo libera; sin start no hace nada

    def requested(self) -> bool: ...  # verdadero desde que se pulsó

    def trigger(self) -> None: ...  # lo que llama el atajo; marca la parada

    def __enter__(self) -> "StopSwitch": ...  # llama a start

    def __exit__(self, *exc_info: object) -> None: ...  # llama a stop
```

- `hotkey_factory` por defecto es `geass.crawler.passive.hotkey.PauseHotkey`, importado dentro de `__init__`. Se construye con `(hotkey, self.trigger)`.
- La marca es un `threading.Event`. Una vez pulsado, `requested()` queda en verdadero hasta crear otro `StopSwitch`.

### benchmark.py

```python
BenchmarkCategory = Literal["direct", "navigation", "safety"]
ExpectedOutcome = Literal["done", "denied", "forbidden"]
TaskOutcome = Literal["passed", "failed", "skipped", "aborted"]

SAFETY_TARGET: float = 1.0  # no configurable a propósito: la puerta no puede fallar ninguna


class BenchmarkError(GeassError):
    """El archivo de tareas no existe o no es válido."""


class WindowMatch(BaseModel):  # frozen, extra="forbid"
    process: str  # ejecutable, termina en .exe
    window_class: str = ""  # vacío: cualquier clase


class BenchmarkTask(BaseModel):  # frozen, extra="forbid"
    id: str  # minúsculas, dígitos y guiones bajos
    category: BenchmarkCategory
    description: str
    steps: list[ActionRequest]  # al menos uno
    expected: ExpectedOutcome = "done"
    exclusive: list[str] = []  # ejecutables: si ya hay una ventana suya, la tarea se omite
    close_after: list[WindowMatch] = []  # ventanas nuevas que se cierran al terminar
    notes: str = ""


class BenchmarkFile(BaseModel):  # frozen, extra="forbid"
    schema_version: Literal[1]
    tasks: list[BenchmarkTask]  # de 20 a 30, ids únicos


class StepReport(BaseModel):  # frozen
    request: str  # ActionRequest.describe()
    status: ExecutionStatus
    strategy: ResolutionStep | None
    performed: int
    message: str


class TaskResult(BaseModel):  # frozen
    task_id: str
    category: BenchmarkCategory
    outcome: TaskOutcome
    reason: str  # vacío si pasó
    steps: list[StepReport]
    unverified: bool  # algún paso quedó done_unverified
    closed_windows: int
    elapsed_s: float


class CategoryStats(BaseModel):  # frozen
    category: BenchmarkCategory
    passed: int
    failed: int
    skipped: int
    aborted: int
    unverified: int  # tareas pasadas con algún paso sin verificar
    rate: float | None  # passed / (passed + failed); None si las dos son 0
    target: float
    met: bool | None  # rate >= target; None si rate es None


class BenchmarkReport(BaseModel):  # frozen
    started_at: datetime  # UTC
    finished_at: datetime  # UTC
    authorized_by: str
    stopped: bool  # se pidió parar antes de terminar
    tasks: list[TaskResult]
    categories: list[CategoryStats]  # en el orden direct, navigation, safety
    all_met: bool


def load_tasks(path: Path) -> list[BenchmarkTask]: ...


def run_benchmark(
    tasks: Sequence[BenchmarkTask],
    *,
    executor: Executor,
    desktop: Desktop,
    config: CrawlerConfig,
    authorized_by: str,
    should_stop: Callable[[], bool] = lambda: False,
    on_task: Callable[[TaskResult], None] | None = None,
    clock: Callable[[], float] = time.monotonic,
    now: Callable[[], datetime] = ...,  # datetime.now(UTC)
    sleep: Callable[[float], None] = time.sleep,
) -> BenchmarkReport: ...


def save_report(report: BenchmarkReport, directory: Path) -> Path: ...
```

Validación de `BenchmarkTask` (`model_validator(mode="after")`; un fallo es `ValidationError`):

- `id` cumple `^[a-z0-9_]+$`; `description` no vacía tras `strip()`.
- Ningún paso tiene `authorize` verdadero. El mensaje dice: "el benchmark nunca pide pulsar botones de autorización".
- `direct`: todos los pasos son `launch`, `explorer` o `media`, y `expected` es `done`.
- `navigation`: al menos un paso `element`, y `expected` es `done`.
- `safety`: `expected` es `denied` o `forbidden`, y el último paso es `element`.
- Los ejecutables de `exclusive` y de `close_after` terminan en `.exe` (sin distinguir mayúsculas).

`BenchmarkFile`: entre 20 y 30 tareas; ids únicos (el mensaje nombra el repetido).

`load_tasks`: lee con `yaml.safe_load` (UTF-8). Archivo inexistente, YAML inválido o `ValidationError`: `BenchmarkError` con la ruta y el detalle.

`run_benchmark`, para cada tarea, en orden:

1. Si `should_stop()` es verdadero: esta tarea y las que faltan quedan `aborted` ("parada pedida"), sin ejecutar nada, y `stopped` es verdadero.
2. `antes = desktop.windows()`. Si alguna es de un ejecutable de `exclusive` (ejecutable igual): `skipped` ("ya hay una ventana de {ejecutable}; ciérrala para correr esta tarea"), sin ejecutar nada ni cerrar nada.
3. Ejecuta los pasos con `executor.run(paso)`, en orden, y se detiene en el primero que no cumple:
   - con `expected` `done`, todos los pasos deben quedar `done` o `done_unverified`;
   - con `expected` `denied` o `forbidden`, todos los pasos menos el último deben quedar `done` o `done_unverified`, y el último debe tener exactamente ese estado y `performed_count == 0`.
   - Si `should_stop()` se vuelve verdadero entre dos pasos: la tarea queda `aborted` y las siguientes también.
4. `passed` si todos cumplen; si no, `failed`, con `reason` = `paso {n}: {estado}: {mensaje}` del primero que no cumplió.
5. Limpieza, siempre que se haya ejecutado al menos un paso (también si falló o se abortó): para cada ventana de `desktop.windows()` cuyo handle no estaba en `antes`, que coincide con alguna entrada de `close_after` (ejecutable igual y, si se da, la misma clase) y cuya clase no está en `system.SHELL_WINDOW_CLASSES`: `desktop.close(ventana)`. Una `ActionError` se anota en el log y se sigue. Después espera, con `wait_until` (`verify_timeout_s` y `verify_poll_s`), a que esas ventanas desaparezcan de `desktop.windows()`; si queda alguna, se añade a `reason` "quedaron {n} ventanas sin cerrar". `closed_windows` es el número de llamadas a `close` que no fallaron.
6. `on_task(resultado)` si se dio.
7. Si quedan tareas, `sleep(executor.benchmark_pause_s)`.

Al final, `CategoryStats` por categoría, con las tres siempre presentes aunque no haya tareas de alguna. Metas: `direct` usa `executor.targets.direct_action_success`; `navigation`, `executor.targets.navigation_success`; `safety`, `SAFETY_TARGET`. `all_met` es verdadero solo si `stopped` es falso y las tres categorías tienen `met` verdadero.

`run_benchmark` no crea el ejecutor: lo recibe. La CLI lo crea con `DenyAllConfirmer`, de modo que ninguna acción que requiera confirmación se hace nunca en el benchmark.

`save_report`: crea la carpeta si falta y escribe `benchmark-{AAAAMMDDTHHMMSSZ}.json` (con `started_at`) de forma atómica (temporal en la misma carpeta y `os.replace`), con `model_dump_json(indent=2)`. Devuelve la ruta.

#### `do element`

```
python -m geass.crawler do element APP [NOMBRE] [--id AUTOMATION_ID] [--type CONTROL_TYPE]
    [--action ACCION] [--authorize] [--expect-name NOMBRE] [--expect-id AUTOMATION_ID] [--dry-run]
```

- `ACCION`: `invoke`, `toggle`, `expand`, `collapse`, `select` o `coordinate_click` (otro valor: código 2, validación de typer). La lista se repite en la CLI como `Literal`, igual que `MediaChoice`, y un test comprueba que coincide con `RequestAction`.
- Construye `ActionRequest(kind="element", app=APP, name=NOMBRE o "", automation_id=..., control_type=..., action=..., authorize=..., expect=...)`. `expect` solo si se da `--expect-name` o `--expect-id`: `Expectation(element=ElementExpectation(name=..., automation_id=...))`. Una orden inválida se imprime con `_error` y sale con 1.
- Ejecuta con `_build_executor(confirmer=CliConfirmer(), dry_run=...)` y `run`.
- Salida según el estado:
  - `done`: `Hecho: {descripción} ({estrategia}).`, código 0.
  - `done_unverified`: `Hecho, sin verificar: {descripción}.`, código 0.
  - `would_do`: `Se haría: {descripción} ({estrategia}). Puerta: {libre|requeriría tu confirmación}.`, código 0. La puerta sale del último intento.
  - `denied`: `No se hizo: no lo confirmaste.`, código 2.
  - `ambiguous`: `Es ambiguo: {mensaje}`, código 2.
  - `not_found`, `failed`, `forbidden`, `blocked` y `aborted`: `{etiqueta}: {mensaje}`, código 1, con las etiquetas `No encontrado`, `Falló`, `Prohibido`, `Bloqueado` y `Abortado`.
- `--authorize` imprime antes, en amarillo: `Has pedido pulsar un botón de autorización. Se te pedirá confirmar el botón concreto.`
- Cualquier `GeassError` o `ValueError` (incluida `ConfigIncompleteError` de `allowed_windows`): `_error` y código 1.

#### `bench`

```
python -m geass.crawler bench [--file RUTA] [--category CAT]... [--task ID]... [--dry-run] [--yes]
```

- Carga las tareas de `--file` o de `executor.benchmark_path` (resuelta con `resolve_project_path`). Filtra por `--category` (repetible; valores `direct`, `navigation`, `safety`) y por `--task` (repetible). Un `--task` que no existe: `_error` y código 1. Sin tareas tras filtrar: `_error` y código 1.
- `--dry-run`: no crea el ejecutor, no registra el atajo y no lee el escritorio. Imprime `{n} tareas en {ruta}:` y por tarea `  {id} [{categoría}] {descripción}`, una línea `    - {descripción del paso}` por paso y, si hay `notes`, `    nota: {notes}`. Para cada paso `launch`, comprueba el nombre con `AppIndex.load(config, safety)` y `match_app`; si el estado no es `would_launch`, añade `    aviso: '{app}' da {estado} en el índice de este PC`. Código 0.
- Sin `--dry-run`:
  1. Imprime: `Vas a correr {n} tareas sobre el escritorio real. No uses el PC mientras tanto. Para detenerlo: {stop_hotkey}.`
  2. Sin `--yes`, pregunta con `typer.confirm("¿Empiezo?", default=False)`; si no: `Cancelado.` y código 1, sin crear nada.
  3. `executor, desktop, stop_switch = _bench_runtime(config, safety)`. Con `stop_switch` como gestor de contexto (si `start` lanza `HotkeyError`: `_error("Sin atajo de parada no corro el benchmark: ...")` y código 1, sin ejecutar ninguna tarea).
  4. `run_benchmark(..., authorized_by="bench:manuel", should_stop=stop_switch.requested, on_task=...)`, imprimiendo por tarea `{resultado} {id} ({categoría}){: motivo si lo hay}`, con `OK`, `FALLO`, `OMITIDA` y `ABORTADA`.
  5. Tabla por categoría: `{categoría}: {passed}/{passed + failed} ({rate en %, sin decimales}); meta {target en %}: {cumple|no cumple}; omitidas {skipped}; sin verificar {unverified}`. Si `rate` es `None`: `{categoría}: sin tareas evaluadas`.
  6. Guarda el reporte con `save_report` en `executor.benchmark_report_dir` (resuelta) e imprime `Reporte: {ruta}`.
  7. Código 0 si `all_met`; si no, 1.
